# 智能协同云图库系统功能问答知识库
## 一、云图库系统基础问题
### 1. 什么是智能协同云图库系统？
智能协同云图库系统是一个集图片素材管理、团队协同创作、多模态AI增强、零代码应用生成于一体的智能化数字素材管理平台，适配个人创作者、中小设计团队、中小企业三类目标用户。系统实现了图片从上传、审核、存储、检索、编辑到分享的全生命周期管理，同时提供实时协同编辑、AI情绪推图、RAG知识库问答、零代码展示网站一键生成等增值功能，解决了传统云图库协同能力不足、多模态AI融合度低、素材价值转化门槛高的痛点。

### 2. 系统支持哪些角色？不同角色有什么权限？
系统采用基于RBAC的五级角色权限体系，不同角色权限边界清晰：
- **系统管理员**：拥有全平台最高权限，可管理所有用户、审核所有图片、管理所有团队空间与应用、查看全平台操作日志。
- **团队管理员（空间创建者）**：可创建团队空间，管理团队成员（添加/删除/修改权限），对团队空间内的图片进行全量操作（上传/编辑/删除/协同编辑），管理团队生成的应用。
- **团队编辑者**：可在团队空间内上传、编辑、协同编辑图片，下载、分享图片，使用团队空间内的AI功能。
- **团队浏览者**：仅可在团队空间内浏览、下载、分享图片，无编辑、删除、协同编辑权限。
- **普通用户**：可使用公共图库、创建私有空间、管理个人图片、使用个人AI功能、生成个人零代码应用，可加入其他用户创建的团队空间。

### 3. 系统的开发和运行环境是什么？
**开发环境**：
- 前端：基于Node.js 22.x环境，使用WebStorm 2025.2开发，Vite 6.0.1构建，核心技术栈为Vue 3.5.13 + ant-design-vue 4.2.6 + TypeScript 5.6.3。
- 后端：基于JDK 21环境，使用IntelliJ IDEA 2025.3.1.1开发，Maven 3.9.x构建，核心技术栈为Spring Boot 3.5.7 + MyBatis-Plus 3.5.15 + Sa-Token 1.39.0。
- 数据库管理：使用Navicat Premium 17管理MySQL数据库。

**生产运行环境**：
- 服务器：阿里云ECS 2核4G云服务器，CentOS 7.9 64位操作系统，5Mbps固定带宽。
- Web服务器：Nginx 1.24.0，用于前端静态资源分发与后端接口反向代理。
- 数据库与中间件：MySQL 8.0.36（主从复制）、Redis 6.2.14、Disruptor 3.4.2。
- 对象存储：腾讯云COS（上海地域，存储桶名称：yun-picture-1351791618）。
- AI服务：集成DeepSeek API（文本处理）与阿里云AI API（图片处理）。

## 二、用户与权限管理相关问题
### 1. 如何注册和登录系统？
未登录用户可以浏览系统主页的公开内容与低清缩略图，若需要查看高清图片或使用核心功能（如上传、编辑、AI功能），系统会自动跳转到登录/注册页面。
- **注册**：用户填写账号、密码等信息，系统校验账号唯一性后，使用BCrypt非对称加密算法对密码进行加密存储，注册成功后自动登录。
- **登录**：用户输入账号密码，系统校验密码正确性后，基于Sa-Token生成用户Token并存储在Redis中，完成登录后跳转至系统主页。

### 2. 忘记密码怎么办？
目前系统暂不支持自助找回密码，若忘记密码，请联系系统管理员，管理员核实身份后可协助重置密码。后续版本将上线邮箱/手机验证码找回密码功能。

### 3. 如何修改个人信息和头像？
登录后进入个人中心，可进行以下操作：
- **修改账号密码**：需输入原密码进行校验，校验通过后可设置新密码，新密码同样经过BCrypt加密存储。
- **修改个人简介**：直接编辑个人简介内容，保存后实时更新。
- **更换头像**：选择本地图片，系统校验格式与大小后，上传至腾讯云COS，更新用户头像URL。

### 4. 系统的权限体系是怎样的？
系统实现了**三级权限管控**：
- **系统级权限**：区分系统管理员与普通用户，系统管理员可访问后台管理模块，普通用户仅可访问前台业务模块。
- **团队级权限**：区分团队管理员、编辑者、浏览者，不同角色在团队空间内的操作权限不同。
- **素材级权限**：区分公共图库、私有图库、团队共享图库，公共图库所有用户可见，私有图库仅创建者可见，团队共享图库仅团队成员可见。

## 三、图片素材全生命周期管理相关问题
### 1. 如何上传图片？支持哪些格式？
用户可在公共空间、私有空间、团队空间上传图片（需拥有对应空间的上传权限）：
- **上传流程**：选择目标空间，选择本地图片，系统前端校验图片格式（支持JPG、PNG、GIF、WebP等主流格式）与大小（单张图片最大支持2GB），生成缩略图后，采用分块上传策略（每块5MB）上传至腾讯云COS，同时将图片元数据（路径、标签、状态等）写入MySQL数据库，图片状态默认设为“待审核”。
- **注意事项**：公共空间上传的图片需经过系统管理员审核通过后才可展示；私有空间与团队空间上传的图片无需审核，直接展示。

### 2. 图片上传后为什么需要审核？审核流程是怎样的？
公共空间图片面向所有用户展示，为保障内容合规性，需经过系统管理员审核：
- **审核流程**：系统管理员进入后台审核模块，查看待审核图片列表，可选择“通过”或“驳回”：
  - 审核通过：图片状态更新为“已通过”，在公共空间展示。
  - 审核驳回：图片状态更新为“已驳回”，删除腾讯云COS中的图片文件，记录驳回原因并通知用户。

### 3. 如何检索图片？有哪些检索方式？
系统支持多维度图片检索，不同空间的检索方式略有差异：
- **通用检索方式**：所有空间均支持关键词检索、标签检索、类型检索、格式检索、日期检索，可单独使用也可联合使用。
- **主色调检索**：仅支持在私有空间或团队空间使用（公共空间数据量庞大，数据库压力大），用户手动选择目标颜色，系统计算图片主色值与目标颜色的余弦相似度，按相似度从高到低排序返回结果。
- **检索流程**：选择目标检索空间，输入/选择检索条件，提交后系统在数据库中模糊匹配/计算相似度，返回匹配的图片列表。

### 4. 可以对图片进行哪些操作？
不同空间、不同角色的图片操作权限不同：
- **公共空间**：所有登录用户可下载、分享图片。
- **私有空间**：创建者可下载、删除、分享、设置头像、编辑、AI图片分析图片。
- **团队空间**：
  - 团队浏览者：仅可下载、分享图片。
  - 团队编辑者/管理员：可下载、删除、分享、编辑、AI图片分析图片。
- **操作说明**：
  - 下载：从腾讯云COS获取临时下载链接。
  - 分享：生成加密分享链接与提取码，设置有效期。
  - 编辑：支持基础裁切旋转（提供主流宽高比例）与高级编辑（AI扩图、AI一键超清）。
  - AI图片分析：将图片喂给后端大模型，以专业角度分析图片内容，流式返回结果。

### 5. 如何使用AI处理图片？有哪些AI功能？
系统提供多种AI图片处理功能，操作流程如下：
- **进入编辑页面**：选择目标图片，点击编辑，进入图片编辑页面。
- **选择AI功能**：
  - **AI扩图**：输入扩图尺寸，系统调用阿里云AI API进行扩图，生成结果图片后上传至COS，保存为新图片版本。
  - **AI一键超清**：系统调用阿里云AI API提升图片清晰度，生成结果图片后上传至COS，保存为新图片版本。
- **保存结果**：预览AI处理结果，确认后保存，可在图片版本管理中查看历史版本。

## 四、团队空间协作相关问题
### 1. 如何创建团队空间？
登录后进入团队空间模块，点击创建团队空间：
- **普通用户**：仅可创建1个普通版团队空间，若空间大小不够用，可联系系统管理员升级空间。
- **系统管理员**：可创建全级别团队空间（普通版、专业版、旗舰版），支持自定义空间容量与存储照片数量。
- **创建流程**：填写空间名称，选择空间级别，系统校验用户是否已创建过团队空间（普通用户），校验通过后创建团队空间，设置创建者为团队管理员。

### 2. 如何添加和管理团队成员？
团队管理员可在团队空间内管理成员：
- **添加成员**：进入成员管理页面，输入目标用户ID，选择成员角色（浏览者/编辑者），提交后系统校验目标用户是否存在、是否已在团队中，校验通过后添加成员。
- **修改成员权限**：选择目标成员，修改其角色（仅可修改其他成员权限，不可修改自身管理员权限）。
- **删除成员**：选择目标成员，确认后删除其团队成员身份。

### 3. 团队成员的权限有什么不同？
团队成员分为三个角色，权限差异如下：
- **团队管理员**：拥有团队空间最高权限，可管理成员、管理所有图片、进行协同编辑、管理团队应用。
- **团队编辑者**：可上传、编辑、协同编辑、下载、分享图片，使用团队AI功能，可修改/删除自己生成的团队应用。
- **团队浏览者**：仅可浏览、下载、分享图片，无编辑、删除、协同编辑权限。

### 4. 如何进行团队图片协同编辑？
团队编辑者与管理员可进行团队图片协同编辑：
- **进入编辑模式**：选择目标图片，点击编辑，系统尝试获取图片编辑锁（基于Redis分布式锁）：
  - 若获取锁成功：进入编辑模式，其他用户仅可进入只读模式，禁用编辑按钮。
  - 若获取锁失败：提示图片正在被编辑，进入只读模式。
- **实时协同编辑**：编辑者的操作通过WebSocket全双工协议传输至后端，结合Disruptor无锁队列处理高并发事件，通过Redis Pub/Sub广播操作事件，其他在线用户的界面实时同步编辑效果。
- **团队聊天**：编辑过程中，所有在线团队成员可通过团队聊天框交流，编辑者可询问其他成员的建议。
- **释放锁**：编辑完成后保存并退出，释放图片编辑锁，其他用户可进入编辑模式。

## 五、AI智能助手相关问题
### 1. AI情绪推图功能怎么使用？
AI情绪推图功能通过识别用户情绪推荐对应主色调的图片，流程如下：
- **进入功能页面**：登录后进入智能助手页面，点击情绪检测按钮。
- **初始化模型**：系统初始化自主训练的情绪检测模型，模型在用户本地浏览器运行（基于ONNX Runtime Web），不上传用户原始人脸数据，保障隐私安全。
- **打开摄像头**：浏览器请求打开用户摄像头，用户同意后开始连续采集10秒数据。
- **情绪识别**：前端模型逐帧推理，取10秒内出现概率最高的情绪类型。
- **推荐图片**：将情绪传输至后端，后端通过提示词工程将情绪映射为对应主色调（如开心→红色、恐惧→黑色），从数据库中查找相似度最高的前5张图片，将图片URL插入预设回复模板，流式返回给前端，前端实时渲染回复与图片。

### 2. 基于系统知识库的问答助手能回答哪些问题？
切换至RAG智能体模式，可询问关于系统的所有问题，包括但不限于：
- 系统功能类：如何上传图片、如何创建团队空间、AI功能有哪些。
- 系统操作类：怎么修改密码、怎么检索图片、怎么生成零代码应用。
- 系统规则类：不同角色有什么权限、图片审核需要多久、空间容量限制是多少。
- 常见问题类：图片上传失败怎么办、协同编辑冲突怎么处理、系统支持哪些浏览器。
- **回答流程**：输入问题，系统对问题向量化，从Milvus向量数据库中检索匹配的系统知识库片段，将片段与问题拼接为Prompt传入DeepSeek大模型，生成基于知识库的精准回答，流式返回结果。

### 3. 如何使用AI图片分析功能？
选择目标图片，点击“AI图片分析”：
- 系统将图片URL喂给后端多模态大模型（基于LangChain4j调度）。
- 通过提示词工程以专业角度分析图片内容（如图片主题、色彩搭配、构图建议等）。
- 分析结果流式返回给前端，用户可实时查看分析内容。

## 六、零代码应用生成相关问题
### 1. 如何生成零代码应用？
系统支持一键生成零代码展示应用，流程如下：
- **选择素材**：从自己的私有空间或加入的团队空间中选择需要使用的图片素材。
- **描述需求**：输入文字描述，说明想创建的应用功能以及图片素材的使用位置。
- **生成应用**：点击开始生成，后端通过提示词工程判断应用复杂度：
  - 简单应用：生成单文件HTML（内联CSS/JS）。
  - 中等复杂度应用：生成多文件分离的HTML、CSS、JS代码。
  - 复杂应用：生成完整Vue工程代码。
- **构建部署**：通过Hutool的RuntimeUtil结合Java的Process执行命令，若为Vue工程，执行npm install依赖安装与npm run build打包命令，将构建产物部署至Nginx静态资源目录，自动配置访问路由。
- **完成生成**：返回应用访问地址，用户可预览生成的应用。

### 2. 生成的应用可以修改吗？如何修改？
系统支持精准修改应用页面元素：
- **进入应用预览**：进入已生成的应用预览页面。
- **选择元素**：点击要修改的页面元素，系统高亮选中元素。
- **输入修改需求**：在弹出的输入框中输入修改需求（如“修改文字颜色为红色”“更换这张图片”）。
- **执行修改**：后端通过大模型定向修改对应代码，热更新部署后实时展示修改效果。

### 3. 如何管理生成的应用？
不同角色的应用管理权限不同：
- **系统管理员**：可全权管理所有应用，包括精选应用（在应用生成界面展示）、修改应用、删除应用。
- **普通用户**：可浏览管理员精选的应用，仅可修改、删除自己生成的应用。
- **管理流程**：进入应用管理模块，选择目标应用，执行修改/删除/精选操作。

### 4. 应用生成支持哪些复杂度？
系统根据用户需求描述自动判断应用复杂度，匹配不同的生成方案：
- **简单应用**：单文件HTML，包含内联CSS与JS，适合简单的展示页面，生成速度快（约5秒）。
- **中等复杂度应用**：多文件分离的HTML、CSS、JS代码，适合有一定交互需求的页面，生成速度中等（约10秒）。
- **复杂应用**：完整Vue工程代码，适合复杂的交互展示页面，生成速度较慢（约15秒），需执行依赖安装与打包构建。

## 七、常见问题与使用技巧
### 1. 图片上传失败怎么办？
图片上传失败可从以下方面排查：
- 检查图片格式：仅支持JPG、PNG、GIF、WebP等主流格式。
- 检查图片大小：单张图片最大支持2GB，若图片过大，可压缩后再上传。
- 检查网络状态：确保网络连接稳定，若网络波动，可稍后重试。
- 检查空间权限：确保拥有目标空间的上传权限。

### 2. 协同编辑时遇到冲突如何处理？
系统通过Redis分布式锁实现编辑状态的互斥控制，避免冲突：
- 若图片正在被其他用户编辑，仅可进入只读模式，可通过团队聊天框与编辑者沟通，等待编辑完成后再进入编辑模式。
- 若自己是编辑者，完成编辑后请及时保存并退出，释放编辑锁，方便其他成员使用。

### 3. 如何保障数据安全？
系统从多方面保障数据安全：
- **身份认证**：基于Sa-Token实现用户身份认证，密码采用BCrypt非对称加密存储。
- **权限管控**：三级权限管控，杜绝越权访问。
- **隐私保护**：AI情绪推图的模型在前端本地运行，不上传用户原始人脸数据。
- **数据存储**：图片存储在腾讯云COS，支持多副本冗余，保障数据不丢失。
- **操作审计**：全量用户操作行为日志留存，所有操作可追溯。

### 4. 系统支持哪些浏览器？
系统支持主流现代浏览器，推荐使用：
- Chrome 90及以上版本
- Edge 90及以上版本
- Firefox 88及以上版本
- Safari 14及以上版本
- 注意：不建议使用IE浏览器，可能存在兼容性问题。
